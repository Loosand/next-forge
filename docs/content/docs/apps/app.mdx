<Tip>The `app` application runs on port 3000 and includes both authenticated app pages and public marketing pages.</Tip>

next-forge exports the main app from the `apps/app` directory. It combines the authenticated application and public marketing site in a single Next.js application using route groups.

## Overview

The `app` application is the main user-facing application built on [Next.js](https://nextjs.org). It includes:
- **Marketing Pages** (`(marketing)` route group): Public pages like homepage, blog, pricing, and contact
- **Authenticated App** (`(app)` route group): Protected pages requiring user login
- **Auth Pages** (`(auth)` route group): Sign-in and sign-up flows

All pages support internationalization through the `[locale]` dynamic segment.

## Features

- **Design System**: The app is connected to the [Design System](/packages/design-system/components) and includes a variety of components, hooks, and utilities to help you get started.
- **Authentication**: The app includes a fully-featured [authentication system](/packages/authentication) with support for email login. You can easily extend it to support other providers and authentication methods. The app is also broken into authenticated and unauthenticated route groups.
- **Database**: The app is connected to the [Database](/packages/database) and can fetch data in React Server Components.
- **Collaboration**: The app is connected to the [Collaboration](/packages/collaboration) and contains Avatar Stack and Live Cursor components.
