# Folder: /packages/logger

1. **地位**: 统一日志输出层，提供环境感知的日志记录能力，自动在服务端使用美化输出、客户端使用 console。
2. **逻辑**: 通过 Proxy 懒加载机制，根据运行环境自动选择 signale（服务端）或 console 包装器（客户端），提供一致的日志 API。
3. **约束**: 必须保持服务端/客户端 API 一致性，所有日志方法必须同时支持两种环境，严禁在初始化时执行副作用（避免循环依赖）。

## 成员清单

- `index.ts`: 日志核心实现 (环境感知的 Logger 工厂 + Proxy 懒加载)
  - Logger 类型定义（10 个日志方法）
  - createLogger() - 环境检测与实例创建
  - logger - Proxy 导出（懒加载入口）

- `package.json`: 包配置与依赖声明
  - dependencies: signale（服务端美化日志）
  - devDependencies: @types/signale（类型定义）

- `tsconfig.json`: TypeScript 编译配置

- `README.md`: 使用文档
  - 特性介绍、API 参考、使用示例
  - 技术实现说明（懒加载、环境检测）
  - 维护指南与同步协议

- `.folder.md`: 本文件（文件夹级文档）
