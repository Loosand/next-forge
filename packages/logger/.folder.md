# Folder: /packages/logger

1. **地位**: Wide Events 日志层，基于 evlog 提供结构化的请求级日志记录，每个请求输出一条包含所有上下文的日志。
2. **逻辑**: 通过 `createRequestLogger` 为每个请求创建日志器，使用 `log.set()` 累积上下文，最后 `log.emit()` 输出完整的 wide event。
3. **约束**: 必须在请求结束时调用 `emit()` 输出日志，错误场景使用 `createError` 创建结构化错误，严禁使用传统的分散日志调用。

## 成员清单

- `index.ts`: evlog 适配器核心实现
  - `initEvlog()` - 初始化 evlog（自动调用）
  - `createRequestLogger(request)` - 为 API Route 创建请求日志器
  - `createActionLogger(actionName)` - 为 Server Action 创建日志器
  - `createError()` - 创建结构化错误
  - `parseError()` - 解析错误为结构化格式
  - `log` - 简单日志 API

- `package.json`: 包配置与依赖声明
  - dependencies: evlog（wide events 日志库）

- `tsconfig.json`: TypeScript 编译配置

- `README.md`: 使用文档
  - Wide Events 概念介绍
  - API 参考、使用示例
  - 最佳实践指南

- `.folder.md`: 本文件（文件夹级文档）
