# Folder: /packages/trigger

1. **地位**: 后台任务处理层，基于 Trigger.dev v4 管理所有异步任务、定时任务和长时间运行的作业。
2. **逻辑**: 定义任务（tasks/），通过 @trigger.dev/sdk 的 task() 创建，由应用层通过 tasks.trigger() 触发执行。
3. **约束**: 任务必须幂等，严禁在任务中直接返回敏感信息，所有数据库操作通过 @repo/database 进行。

## 成员清单

- `trigger.config.ts`: Trigger.dev 配置文件（项目ID、运行时、重试策略等）
- `index.ts`: 统一导出入口，导出所有任务和工具函数
- `keys.ts`: 环境变量配置（TRIGGER_SECRET_KEY）
- `tasks/`: 任务定义目录
  - `hello-world.ts`: 示例任务，展示基本任务结构
  - `fal-run.ts`: 通用 fal.ai 任务，支持调用任意 fal.ai 端点
  - `fal-models.ts`: 预定义的类型安全 fal.ai 模型触发器（NanoBanana 系列等）
- `types/`: 类型定义目录
  - `fal.ts`: fal-run 任务的 Payload 和 Result 类型

## 使用方式

在应用中触发任务：

```typescript
import { helloWorldTask, falRunTask, triggerNanoBanana } from "@repo/trigger";

// 触发 hello world 任务
const handle = await helloWorldTask.trigger({ name: "User" });

// 等待结果（可选）
const result = await handle.wait();

// 触发 fal.ai 任务（通用方式）
const falHandle = await falRunTask.trigger({
  endpointId: "fal-ai/flux/dev",
  input: { prompt: "A sunset", image_size: "landscape_16_9" },
  metadata: { userId: "user_123" },
});
const falResult = await falHandle.wait();

// 触发 fal.ai 任务（类型安全方式）
const nanoBananaHandle = await triggerNanoBanana({
  input: { prompt: "A sunset" },  // ✅ 完整类型提示
});
const nanoBananaResult = await nanoBananaHandle.wait();
```

## 开发命令（从根目录运行）

```bash
bun run trigger:dev     # 启动本地开发服务器
bun run trigger:deploy  # 部署任务到 Trigger.dev 云端
```
